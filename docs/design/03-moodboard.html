ResultRelay · design direction

An instrument panel for a regulator,
not a dashboard for a startup.

One accent. Colour only where it means something. Density that earns its space. Motion that shows a chain of custody rather than decorating a page. The product's credibility is its willingness to show what it refused to do — so every screen carries its own limits, adjacent to its claims.

01 — Reference board

Stripe DashboardHierarchy by typography and whitespace, not colour. Colour reserved for status. Microcopy carries the trust.
LinearDensity without clutter; separate "doing" from "analysing"; every row is a live object with six states.
VercelOne question, one answer above the fold; logs one click deeper. Status as a dot, never a paint bucket.
GSAPOne curve, three durations, timelines that can be scrubbed and context-reverted. matchMedia() for reduced motion.
Magic UIBorrowed patterns, not dependency: blur-fade, number ticker, shine border, animated beam, dot pattern — re-implemented in the local token system.
three.jsSpent once, on the pipeline, where position encodes sequence and the gate is a membrane you can see a step stop at.

04 — Motion language

Curve

power2.out — arrives, then settles. No bounce anywhere in a product about compliance.

Durations

120 msstate change, hover
200 mspanel, disclosure
320 msview transition, stagger unit 40 ms

Parity

Every timeline has a prefers-reduced-motion branch: opacity only, 90 ms, no transform. GSAP matchMedia() swaps the branch and reverts cleanly on change.

05 — The one 3-D moment

event → evidence → proposal → gate → transition → state

Steps sit on a receding line; the gate is the plane they must cross. A step that was refused stops at the membrane. Clicking a node moves the page to that step's artefacts — the scene is navigation.

06 — What was rejected

✕Glassmorphism / neon / meteors. A governance instrument wrapped in spectacle argues against its own disclaimer.
✕A 3-D hero with floating particles. three.js would then be decoration, and decoration in this product is a credibility cost.
✕Dark mode in this pass. One theme done properly; two half-done themes would double the contrast debt.
✕Icon-only nav. The domain vocabulary (gate, invariant, acknowledgment) is the product; icons would erase it.
✕Animated counters on every number. A ticker implies live data; most of these numbers are computed once per build.
Measured contrast, GSAP 3 timelines, three.js scene, Magic UI patterns ported to local tokens — no CDN, no remote fonts, so the board and the product render identically offline.
